description: Fetch today's Instagram candidates, pick the best post and write brief.md (Spiking infographic workflow)
---
Do the daily infographic brief, end to end.

1. Run `python3 fetch.py $ARGUMENTS` in this folder. Optional arguments like `--days 14 --per-account 4` may be passed. It prints the dated output folder. If it fails (missing/expired token, HTTP error), stop and report the error. Never print or echo the contents of `.env`.
2. Read `candidates.json` in that folder and view each image in `candidates/`.
3. Prefer topics about US stocks/investing that many retail investors search for (top holdings, best/worst performers, Magnificent 7, how a company makes money, revenue breakdown, dividends, ETF holdings, famous portfolios) that work as a simple list / ranked bars / waterfall infographic.
3b. Check the dated folder for existing `brief.md` / `brief-N.md` files from earlier runs today (by you, a colleague, or the schedule). Read them and collect the post permalinks they already chose. Never pick those again: choose the best post NOT already used. If every candidate was used, rerun fetch with a larger window (`--days 14 --per-account 4`) once; if still none, say so and stop.
4. Pick the ONE best post to inspire a new Spiking infographic: strong engagement rate, one clear takeaway, works as a data visual, timely, not a duplicate of a recent Spiking topic. Skip personal/non-data posts. It is only inspiration: never reproduce another account's graphic or numbers verbatim.
5. Read `style-guide.md` from the parent folder of the dated folder (the OUT_DIR from `.env`; if absent, say so and use a generic blue finance style). Follow it (palette, typography, layout, prompt template). Extra rules: takeaway strip optional (omit by default); simple catchy truthful headline; minimal text; the Spiking logo must be the real spiking-logo-final.png, never AI-generated. In the brief name the closest sample (sample-01..10) to copy, and make the image prompt follow the template in style-guide.md with the hex colors.
6. In the dated folder write the brief. NEVER overwrite or delete earlier ones: if `brief.md` does not exist yet write `brief.md`, otherwise write `brief-2.md`, `brief-3.md`, ... (next free number). The brief containing: chosen post (account, permalink, likes, comments, engagement rate, why chosen, runner-up); topic and the key data points to verify from primary sources, with any number taken from the post clearly marked UNVERIFIED; proposed headline (2 lines, caps; simple, catchy hook such as "How X makes money", truthful to the data), optional one-line subhead, hero visual type, source line, and NO Key Takeaway box unless there is a strong reason; and a filled-in image-generation prompt for ChatGPT following the prompt template in `style-guide.md`.
7. Under a final section "Other ideas" list 3-5 extra trending finance/business topics found with a web search today (title, why it is trending, best data source). Topic ideas only; no copied graphics.
8. Copy the chosen candidate image to `reference.jpg` (or `reference-2.jpg`, `reference-3.jpg` matching the brief number) in the dated folder.
9. Reply with 3 lines max: chosen post, folder path, any warnings.
